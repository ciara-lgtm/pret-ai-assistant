# Coffee Machine Broken — Mock Internal Knowledge

> **MOCK / FICTIONAL DOCUMENT — Technical Interview POC only.**
> This document does not represent actual Pret policies or procedures.

## Purpose

This document provides a fictional procedure for employees reporting a coffee machine that is broken or not operating correctly.

## Reporting a Fault

If a coffee machine is not working:

1. Stop using the machine if normal operation is not possible.
2. Notify the **Shift Manager or Duty Manager**.
3. Record the fault in the store's **Equipment Fault Log**.

The fault record should include:

- Machine location
- Machine type or identifier, if available
- Description of the problem
- Any error message or error code displayed
- Approximate time the problem was noticed
- Whether the machine can still be used safely

## Employee Responsibilities

Employees **should**:

- Follow the approved basic troubleshooting guidance.
- Record relevant error messages.
- Keep the Shift Manager informed if the problem affects service.

Employees **should not**:

- Open the machine casing.
- Remove electrical components.
- Attempt electrical repairs.
- Bypass safety features.
- Continue using equipment that appears unsafe.

## Escalation

The Shift Manager or Duty Manager should review the fault and determine whether maintenance support is required.

If the equipment presents an immediate safety concern, follow the **Equipment Safety Escalation** procedure instead of attempting further troubleshooting.
