# Coffee Machine Troubleshooting — Mock Internal Knowledge

> **MOCK / FICTIONAL DOCUMENT — Technical Interview POC only.**
> This document does not represent actual Pret policies or procedures.

## Purpose

This document provides fictional guidance for safe, basic checks that an employee may perform when a coffee machine is not working normally.

## Basic Checks

Before reporting a routine fault, an employee may:

- Check whether the machine has power.
- Check whether the display is switched on.
- Check whether an error message or error code is displayed.
- Confirm that doors, trays, or removable components intended for normal operation are correctly positioned.
- Follow the machine's normal cleaning or rinse cycle if the machine specifically prompts for it.
- Perform a normal restart using the machine's standard power controls if there is no indication of an electrical or safety problem.

## Do Not Attempt

Employees must **not**:

- Remove the outer casing or panels.
- Access internal electrical components.
- Repair wiring, plugs, switches, pumps, or heating components.
- Bypass an error or safety interlock.
- Use tools to repair the machine.
- Attempt any repair that is not part of normal employee operation.

## Safety Boundary

If the machine produces **smoke, a burning smell, sparks, exposed wiring, unusual electrical sounds, significant leakage, or visible electrical damage**, do not restart or troubleshoot it.

Stop using the machine and follow the **Equipment Safety Escalation** procedure.

Routine troubleshooting must never take priority over employee or customer safety.
